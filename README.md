# StepStamp

## アプリ概要
Next.jsとSupabaseを用いた歩数×スタンプラリーアプリです。

## サイトイメージ
![アプリ画面](https://github.com/milkycocoa/StepStamp/blob/5e219bccd706d95c79597b246d304ba61d7dc2b1/docs/%E3%82%A2%E3%83%97%E3%83%AA%E3%81%AE%E3%82%A4%E3%83%A1%E3%83%BC%E3%82%B8%E7%94%BB%E5%83%8F.png?raw=true)

## サイトURL
https://stepstamp-hk.vercel.app/

## 使用技術
- フロントエンド：Next.js 16.2.0 
- バックエンド：Next.js 16.2.0 
- データベース：Supabase
- デプロイ：Vercel
- バージョン管理：Git、GitHub

## 設計ドキュメント
[要件定義・基本設計・詳細設計の一覧_Googleスプレッドシート](https://docs.google.com/spreadsheets/d/1wSdGdiGyU9LGr3rd3vt0u2Dfvs1y3CO5R5jQeLjqeEY/edit?usp=sharing)

## 機能一覧
- トップ画面での歩数表示・入力
- プロフィールの編集（名前・アイコン）
- スタンプラリーの確認
- 歩数履歴の一覧表示・編集・削除
